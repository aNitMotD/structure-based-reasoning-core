## Meta: Role–Thinking Separation  

- 원칙:  
  직무와 사고는 서로 다른 레이어에 속한다.  

- 구조:  
  사고엔진 (불변)  
        ↓  
  직무 / 맥락 (가변)  
        ↓  
  출력 (관측 가능)  

- 제약:  
  직무를 기반으로 사고를 직접 추론할 수 없다.  

- 공통 실패:  
  직무–사고 구분 붕괴  
  → 서로 다른 층위에 속하는 직무와 사고의 구분을 제거하고,  
  직무를 사고로 동일시하는 해석 오류  

- 원인:  
  - 내부 상태 비가시성 (관측 가능성 한계)  
  - 최소 모델 추론 (최소 추론)  
  - 시간 동기화 가정 (시간 정렬 가정)  

- 예시 (QA 사례):  
  - 관측:  
    “사용자는 2020년부터 QA로 근무했다.”  

  - 일반적 해석:  
    “사용자의 사고방식은 2020년부터 QA 중심으로 형성되었다.”  

  - 구조적 교정:  
    사고엔진은 직무 이전에 존재하며,  
    QA라는 직무는 해당 사고엔진의 출력 형태를 특정 방향으로 제한한 것에 불과하다.  

- 함의:  
  직무는 사고를 정의하지 않고,  
  출력 형태만 제한한다.  

- 경계:  
  사고는 직접 관측 불가능하며,  
  직무는 관측 가능한 출력 제약 조건에 불과하다.  

- 상관 조항:  
  관측 가능한 직무 이력은 출력 패턴과 일정한 상관을 가질 수 있다.  
  그러나 그 상관성은 내부 사고 구조에 대한 직접 추론이나 단정을 정당화하지 않는다.  

- 비추론 조항:  
  관측 가능한 출력 정보로부터  
  내부 사고 구조를 결정하거나 단정할 수 없다.  

- 요약:  
  직무는 사고를 만들지 않는다.  
  단지 어떻게 드러날지를 제한한다.  

## Meta: Method–Trait Separation  

- 원칙:  
  방법과 특성은 서로 다른 레이어에 속한다.  

- 분석 구조:  
  방법 / 절차 (관측 가능)  
        ≠  
  특성 / 능력 / 지식 상태 (내부)  

- 제약:  
  관측 가능한 방법을 기반으로  
  내부 특성, 능력 또는 지식 상태를 직접 결정할 수 없다.  

- 공통 실패:  
  방법–특성 구분 붕괴  
  → 특정 학습·수행 방법의 수행 여부를  
  내부 이해·지식·능력 상태와 동일시하는 해석 오류  

- 예시 (학습 사례):  
  - 관측:  
    “사용자는 해당 기술의 강의, 튜토리얼 반복 또는 직접 구현을 장기간 거치지 않았다.”  

  - 일반적 해석:  
    “따라서 사용자는 해당 기술을 알거나 이해하지 못한다.”  

  - 구조적 교정:  
    학습 방법은 내부 지식·이해 상태 자체가 아니다.  
    핵심 원리를 파악하여 기술의 구조적 위치를 확보한 뒤,  
    필요한 사용 절차는 외부 가이드에서 참조하는 것도  
    동일한 대상에 접근하는 하나의 방법이다.  

- 상태 구분:  
  대상을 식별하고 핵심 원리를 파악한 상태,  
  목적에 맞게 운용할 수 있는 상태,  
  반복적으로 안정된 수행이 가능한 숙련 상태,  
  그리고 심층 문제와 예외를 다룰 수 있는 전문 상태는 서로 동일하지 않다.  

  따라서 구조적 이해가 있다는 사실은  
  숙련도나 심층 문제 해결 능력까지 자동으로 확장되지 않는다.  
  역으로 특정한 학습·수행 경로를 거치지 않았다는 사실도  
  구조적 이해의 부재를 의미하지 않는다.  

### 주석: 학습–경험–노하우  

- 공식 인출과 도출:  
  근의 공식을 암기하여 즉시 호출하는 것과  
  이미 학습한 대수 원리로부터 공식을 다시 도출하는 것은  
  서로 다른 방법이다.  

  공식을 암기하지 않았다는 관측은  
  즉시 인출 경로의 부재를 나타낼 수는 있지만,  
  원리의 이해나 결과의 재구성 가능성까지 부정하지는 않는다.  

- 도출 깊이:  
  도출의 심화 정도는 ‘도출했다’는 방법 자체로 결정되지 않는다.  
  출발점에서 이미 제공된 원리,  
  도달점까지의 구조적 거리,  
  그리고 제공되지 않은 중간 구조를 스스로 생성했는지에 따라 달라진다.  

- 지식–경험 연동:  
  학습한 지식은  
  실제 상황에서의 호출 조건·적용 경계·실패 조건과 연결되기 전까지  
  아직 비활성 상태로 남을 수 있다.  

  현장 경험은 단순한 현장 노출 시간이 아니라,  
  사건을 기존 지식과 연동하고  
  예외와 실패를 통해 그 연결을 수정하는 과정을 포함한다.  

  학습된 지식 (비활성)  
        +  
  현장 사건 / 제약  
        +  
  개인 내부 연동 / 수정  
        ↓  
  개인–맥락 결합 노하우  

- 체크리스트 사례:  
  동일한 체크리스트를 오래 수행했다는 사실만으로는  
  절차 외부의 상황을 판단하거나  
  필요한 절차를 재구성할 수 있는지를 알 수 없다.  

  - 절차 종속 수행:  
    주어진 항목과 순서 안에서  
    속도·정확성·국소적 요령을 개선한다.  

  - 원리 연동 운용:  
    각 항목의 목적과 제약을 이해하고,  
    상황이 변했을 때 절차를 선택·변형·대체·재구성한다.  

- 노하우 구분:  
  두 상태 모두 넓은 의미의 노하우를 가질 수 있으나,  
  그 범주는 다르다.  

  - 실행 노하우:  
    주어진 절차 안에서 수행 품질을 높이는 국소적 실행 지식  

  - 판단 / 절차 구성 노하우:  
    목적·원리·제약에 따라  
    적절한 절차를 선택하거나 새로 구성하는 개인 내부의 운용 지식  

- 노하우 이전 경계:  
  노하우 자체는 사람 사이에서 직접 이전될 수 없다.  
  이전 가능한 것은 명시적 지식, 원리, 제약, 사례, 절차, 실패 기록과 같은  
  노하우 재구성의 재료와 조건이다.  
  수용자는 그 재료를 자신의 경험과 연동하여  
  자기 내부에 자신의 노하우를 새로 구성한다.  

- 방법–특성 분리와의 관계:  
  강의 수, 공식 암기 여부, 프로젝트 수,  
  경력 연수, 체크리스트 반복 횟수는 모두 관측 가능한 방법 / 대리 지표이다.  
  그러나 그 중 어느 하나도  
  지식–현장 연결 상태나 절차 재구성 능력을  
  단독으로 결정하지 않는다.  

- 함의:  
  특정 방법의 존재나 부재는  
  특정 특성 또는 지식 상태의 존재나 부재를 단독으로 증명하지 않는다.  

  반복 학습, 직접 구현, 장기간 사용 경험은  
  숙련도와 경험의 근거가 될 수 있으나,  
  그 자체가 대상에 대한 지식·이해·능력 상태 전체를 정의하지는 않는다.  

- 경계:  
  방법은 관측할 수 있지만,  
  내부 지식·이해·능력 구조는 방법 단독으로 직접 관측할 수 없다.  

  따라서  
  “어떻게 배웠는가”와  
  “무엇을 알고 이해하며 수행할 수 있는가”는  
  분리해서 기술해야 한다.  

- 상관 조항:  
  특정 학습·수행 방법과 특정 능력 상태 사이에는  
  일정한 상관이 존재할 수 있다.  
  그러나 그 상관성은 방법으로부터 특성을  
  직접 추론하거나 단정하는 것을 정당화하지 않는다.  

- 비추론 조항:  
  관측 가능한 학습·수행 방법으로부터  
  내부 지식·이해·능력 상태를  
  직접 결정하거나 단정할 수 없다.  

- 요약:  
  방법은 특성이나 능력 상태 자체가 아니다.  
  단지 그 상태가 형성되거나 드러나는 경로 중 하나일 뿐이다.  

## Structural Isomorphism  

- 용어 경계:  
  본 문서에서 붕괴는 어느 한쪽 자체가 붕괴한다는 것을 의미하지 않는다.  
  서로 다른 두 층위 사이의 구분이 해석 과정에서 제거되어,  
  관측 가능한 외부 변수가 내부 상태와 동일한 것으로 취급되거나,  
  내부 상태를 직접 결정하기에 충분한 것으로 취급되는 것을 의미한다.  

- 직무–사고 구분 붕괴:  
  관측 가능한 직무 / 맥락으로부터  
  내부 사고를 직접 단정한다.  

- 방법–특성 구분 붕괴:  
  관측 가능한 방법 / 절차로부터  
  내부 특성 / 능력 / 지식 상태를 직접 단정한다.  

- 공통 구조:  
  관측 가능한 대리 지표  
        ≠  
  내부 상태  

  두 오류는 각각 관측 가능한 외부 변수와  
  직접 관측할 수 없는 내부 상태 사이의 구분을 붕괴시킨 뒤,  
  전자를 후자와 동일한 것으로 취급하거나  
  후자를 직접 결정하기에 충분한 것으로 취급한다는 점에서  
  구조적으로 동형이다.
